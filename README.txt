嘶く · 乐队练习包

怎么用
  1. 把压缩包整个解压（不要只拖出 index.html）。
  2. 用电脑浏览器打开文件夹里的 index.html（Chrome / Edge / Safari / Firefox 都可以）。
     手机上直接打开本地网页通常读不到旁边的音频，请用电脑，或把整个文件夹放到一个网站空间上再用手机访问。

页面上有什么
  声部    原曲、伴奏、人声、吉他（合）、主音吉他、节奏吉他、原声吉他、键盘、贝斯、鼓
  小节    点一个小节选中它；再点另一个小节，选中两者之间的全部小节；点段落名选中整段。
          选区右边的 ✕ 取消选择，回到整首歌。小节格子里的小字是该小节的和弦。
  循环    开着时，选中的小节播完会回到开头重来；关掉则播完停下。
  速度    0.5× 到 1×，变慢不变调。
  提前一小节进入    从选区的前一小节开始放，方便找拍子进。
  键盘    空格 播放/暂停；← → 把选区前后移一小节；L 开关循环。

文件
  index.html    练习页面
  audio/        各声部音频（AAC，与原分轨同一时间轴）

这首歌：6/8 拍，附点四分音符 = 77，共 128 小节。
